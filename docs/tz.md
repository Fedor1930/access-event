# Техническое задание на ИС AccessEvent
 
## 1. Общие сведения
Полное наименование: AccessEvent — платформа инклюзивных мероприятий.
Заказчик: учебная практика. Разработчик: студент.
 
## 2. Предметная область
Автоматизация процессов поиска, создания и посещения инклюзивных мероприятий для людей с нарушениями слуха, организация инклюзивной среды, чатов и визуальной коммуникации.

## 3. Назначение и цели
Назначение: предоставление слабослышащим пользователям доступа к
мероприятиям с визуальной коммуникацией.

## 5. Нефункциональные требования

## 6. Ограничения
Python 3.11, Flask, PostgreSQL 16, срок 6 дней, бесплатные сервисы.

День 4 — frontend и контейнеризация; День 5 — тестирование и документация;
День 6 — защита.
