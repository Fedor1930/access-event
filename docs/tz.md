# Техническое задание: AccessEvent

## 1. Назначение и цели
AccessEvent — веб-платформа для организации мероприятий с акцентом на доступность для людей с нарушениями слуха.
Цель: обеспечить полный доступ к информации о мероприятиях без необходимости слышать.

## 2. Описание предметной области
Система работает с сущностями: Event, Participant, Organizer, Registration, Notification, Review, Category.
Основные процессы: создание мероприятия, регистрация, визуальные уведомления, чат, отзывы.

## 3. Требования к функциям
- Регистрация и авторизация пользователей
- Создание и редактирование мероприятий организатором
- Регистрация участников и отмена регистрации
- Просмотр и фильтрация мероприятий (инклюзивные / обычные)
- Визуальные уведомления и цветовая индикация статусов
- Текстовый чат на странице мероприятия
- Оставление отзывов и загрузка материалов
- Панель администратора и статистика для владельца

## 4. Требования к качеству
- Время отклика системы < 2 секунды
- Поддержка PostgreSQL 14+
- Python 3.10+, Flask 2.3+
- Соответствие WCAG 2.1 AA (доступность для людей с ОВЗ)
- Безопасное хранение паролей (хеширование bcrypt)
- Защита от SQL-инъекций (через SQLAlchemy ORM)

## 5. Требования к интерфейсу
- Адаптивный дизайн (mobile-first)
- Высокая контрастность, шрифт минимум 16px
- Визуальные уведомления (баннеры с цветовой индикацией)
- Текстовый чат для общения без звука

## 6. Требования к данным
- Реляционная база данных PostgreSQL 14+
- Использование ORM SQLAlchemy
- Минимум 7 таблиц для хранения данных

## 7. Технологический стек
- Язык программирования: Python 3.10+
- Веб-фреймворк: Flask 2.3+
- Шаблонизатор: Jinja2
- База данных: PostgreSQL 14+
- CI/CD и проверка: GitHub Actions + GHCR
- Тестирование: pytest

## 8. Ограничения и допущения
- В текущей версии мобильное приложение не разрабатывается (только веб-версия)
- Интеграция с платёжными шлюзами и видеоконференциями не предусмотрена
- Развёртывание осуществляется через Docker
- Срок выполнения работ: 6 дней (36 часов)
