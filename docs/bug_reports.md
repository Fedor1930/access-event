# Баг-репорты AccessEvent
 
## BUG-01. [Major] Повторная регистрация с тем же email возвращает 500
- Серьёзность: Major. Приоритет: P2.
- Шаги: 1) POST /api/register с email test@mail.ru; 2) повторить с тем же email.
- Фактический результат: 500 Internal Server Error.
- Ожидаемый результат: 400 с понятным сообщением.
- Статус: Исправлен. Решение: проверка занятости email до db.session.commit() в routes/auth.py.
 
## BUG-02. [Major] pytest падает: fixture 'client' not found в test_api.py
- Серьёзность: Major. Приоритет: P1.
- Шаги: запустить pytest -v.
- Фактический результат: все тесты test_api.py в состоянии ERROR.
- Ожидаемый результат: тесты выполняются.
- Статус: Исправлен. Решение: фикстура client вынесена в tests/conftest.py — pytest находит её для всех тестовых файлов.
 
## BUG-03. [Minor] Тест CHECK-ограничения статуса не падает на SQLite
- Серьёзность: Minor. Приоритет: P3.
- Шаги: добавить тест с pytest.raises на вставку статуса 'bogus' в SQLite.
- Фактический результат: тест падает — SQLite не проверяет CHECK.
- Ожидаемый результат: INSERT отклоняется.
- Статус: Не исправлен (причина: ограничение SQLite; в PostgreSQL CHECK из schema.sql работает). Валидация продублирована на уровне API (PATCH отклоняет недопустимый статус 400).
 
## BUG-04. [Trivial] Порт 5000 занят при повторном запуске
- Серьёзность: Trivial. Приоритет: P4.
- Шаги: перезапустить python app.py без остановки предыдущего процесса.
- Фактический результат: Address already in use.
- Ожидаемый результат: сервер стартует.
- Статус: Исправлен. Решение: остановить предыдущий процесс (Ctrl+C) перед повторным запуском.
