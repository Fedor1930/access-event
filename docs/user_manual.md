# Руководство пользователя AccessEvent
 
## 1. Регистрация и вход
1. Откройте http://127.0.0.1:5000/register.
2. Введите имя, email, пароль (не короче 8 символов), выберите роль.
3. Нажмите «Зарегистрироваться», затем войдите через /login.
Для слабослышащих пользователей: все сообщения выводятся текстом, без звуковых сигналов.
 
## 2. Просмотр мероприятий
1. Главная страница показывает список активных мероприятий.
2. Поставьте галочку «Только инклюзивные» для фильтрации.
Для слабослышащих пользователей: фильтр — визуальный элемент, не требует звуковых подсказок.
 
## 3. Создание мероприятия (организатор)
1. В личном кабинете заполните форму: название, дата (ГГГГ-ММ-ДД ЧЧ:ММ), место, описание.
2. Отметьте «Инклюзивное мероприятие» при необходимости.
3. Нажмите «Создать» — появится id мероприятия.
Для слабослышащих пользователей: результат создания показывается текстом.
 
## 4. Регистрация на мероприятие
1. Откройте карточку мероприятия.
2. Нажмите «Зарегистрироваться» — статус pending (жёлтый баннер).
3. После подтверждения организатором статус станет confirmed (зелёный).
Для слабослышащих пользователей: статус показан цветом И текстом.
 
## 5. Текстовый чат
1. В карточке мероприятия находится чат.
2. Введите сообщение и нажмите «Отправить».
3. Сообщения обновляются автоматически каждые 5 секунд.
Для слабослышащих пользователей: чат — основной канал связи, звук не используется.
 
## 6. Визуальные уведомления
1. Уведомления отображаются в личном кабинете блоками с типом [info], [reminder], [cancellation].
2. Кнопка «Отметить все прочитанными» убирает подсветку.
Для слабослышащих пользователей: вместо звука — визуальные блоки.
 
## 7. Отзывы
После мероприятия оставьте оценку от 1 до 5 и комментарий в карточке мероприятия. Один отзыв на мероприятие.
Для слабослышащих пользователей: форма полностью визуальная.
