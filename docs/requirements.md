# Требования AccessEvent
 
## Функциональные требования (FR)
 
| ID | Требование | Приоритет | Реализация |
|---|---|---|---|
| FR-01 | Регистрация по имени, email и паролю | Высокий | День 3 |
| FR-02 | Вход и выдача JWT-токена | Высокий | День 3 |
| FR-03 | Роли guest/user/organizer/admin с наследованием | Высокий | Дни 2-3 |
| FR-04 | Создание мероприятия организатором | Высокий | День 3 |
| FR-05 | Просмотр списка активных мероприятий | Высокий | День 3 |
| FR-06 | Фильтр «только инклюзивные» | Высокий | День 3 |
| FR-07 | Визуальные уведомления (без звука) | Высокий | Дни 3-4 |
| FR-08 | Регистрация на мероприятие со статусами | Высокий | День 3 |
| FR-09 | Текстовый чат мероприятия | Высокий | Дни 3-4 |
| FR-10 | Отзывы с оценкой 1-5 | Средний | День 3 |
| FR-11 | Личный кабинет: мои регистрации и уведомления | Высокий | Дни 3-4 |
| FR-12 | Валидация email и пароля (8+ символов) | Высокий | День 3 |
| FR-13 | Хеширование паролей | Высокий | День 3 |
| FR-14 | ARIA-атрибуты, контраст, skip-link | Высокий | День 4 |
| FR-15 | Цветовая индикация статусов | Средний | День 4 |
 
## Нефункциональные требования (NFR)
 
| ID | Требование |
|---|---|
| NFR-01 | Отклик страницы не более 2 секунд |
| NFR-02 | Пароли хранятся только в виде хешей |
| NFR-03 | Токен действует 24 часа |
| NFR-04 | Интерфейс соответствует WCAG 2.1 AA |
| NFR-05 | Совместимость с актуальными Chrome, Firefox, Edge |
| NFR-06 | Развёртывание одной командой docker compose up |
| NFR-07 | Целостность данных на уровне БД (FK, CHECK, UNIQUE) |
| NFR-08 | Ключевые функции покрыты тестами pytest |
 
## User Stories (US)
 
| ID | История |
|---|---|
| US-01 | Как гость, я хочу зарегистрироваться, чтобы пользоваться платформой |
| US-02 | Как пользователь, я хочу войти по email и паролю |
| US-03 | Как слабослышащий пользователь, я хочу фильтр инклюзивных мероприятий |
| US-04 | Как пользователь, я хочу видеть список мероприятий с датой и местом |
| US-05 | Как пользователь, я хочу записаться на мероприятие одной кнопкой |
| US-06 | Как пользователь, я хочу видеть статус заявки цветом и текстом |
| US-07 | Как слабослышащий пользователь, я хочу визуальные уведомления |
| US-08 | Как пользователь, я хочу общаться в текстовом чате мероприятия |
| US-09 | Как организатор, я хочу создавать мероприятия с пометкой «инклюзивное» |
| US-10 | Как организатор, я хочу подтверждать заявки участников |
| US-11 | Как организатор, я хочу отменить мероприятие с уведомлением участников |
| US-12 | Как админ, я хочу управлять всеми мероприятиями |
| US-13 | Как слабослышащий пользователь, я хочу ARIA-подписи для скринридера |
| US-14 | Как пользователь, я хочу оставить отзыв с оценкой |
| US-15 | Как админ, я хочу видеть статистику регистраций |
