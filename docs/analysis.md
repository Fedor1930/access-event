# Анализ предметной области AccessEvent
 
## 1. Проблема
Люди с нарушениями слуха не могут полноценно участвовать в городских
мероприятиях: информация о доступности публикуется хаотично, живое
общение на событиях без сурдоперевода недоступно.
 
## 2. Целевая аудитория
- слабослышащие пользователи, ищущие доступные мероприятия;
- организаторы, готовые обеспечить доступность событий;
- администратор платформы.
 
## 3. Решение
Веб-платформа AccessEvent: каталог мероприятий с фильтром «инклюзивное»,
регистрация участников со статусами, визуальные уведомления и текстовый
чат вместо аудиокоммуникации.
 
## 4. Сравнение с существующими решениями
 
| Решение | Недостаток | Что делает AccessEvent |
|---|---|---|
| Афиши и соцсети | нет признака доступности | фильтр is_inclusive |
| Ticket-сервисы | нет чата и визуальных уведомлений | текстовый чат + визуальные оповещения |
 
## 5. Ограничения
- срок: 6 дней практики;
- стек: Python/Flask + PostgreSQL;
- бюджет: только бесплатные сервисы (GitHub, dbdiagram.io).
