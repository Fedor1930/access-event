# Оценка ИС AccessEvent
 
## SWOT-анализ
| | Плюсы | Минусы |
|---|---|---|
| Внутреннее | S: полный цикл разработки (ТЗ-проектирование-код-тесты); чат и визуальные уведомления закрывают ключевую потребность | W: нет push-уведомлений; чат обновляется опросом каждые 5 с; нет пагинации |
| Внешнее | O: рост спроса на доступную среду; интеграция с картами и календарями | T: конкуренция с афишами; зависимость от бесплатных лимитов GitHub |
 
## Вывод о готовности
Система готова к опытной эксплуатации в ограниченном круге пользователей: ключевые сценарии покрыты 20 тестами, CI зелёный, документация полная. До промышленной эксплуатации требуется: миграции БД, push-уведомления, нагрузочное тестирование.
 
## Направления модернизации
1. Push-уведомления (Web Push) — мгновенное оповещение без обновления страницы; критично для слабослышащих.
2. Перевод видео в субтитры (ИИ) — доступность видеоматериалов мероприятий.
3. Мобильное приложение (PWA) — уведомления на телефоне.
4. Реферальная система — рост аудитории через приглашения.
