# Тест-кейсы AccessEvent
 
| ID | Название | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|---|
| TC-01 | Регистрация с валидными данными | email свободен | POST /api/register (anna, anna@mail.ru, Passw0rd!, user) | 201, user_id |
| TC-02 | Регистрация с занятым email | email уже существует | POST /api/register с тем же email | 400, сообщение об ошибке |
| TC-03 | Регистрация с некорректным email | email без @ | POST /api/register (not-an-email) | 400 |
| TC-04 | Пароль короче 8 символов | пароль «123» | POST /api/register | 400 |
| TC-05 | Вход корректный | пользователь существует | POST /api/login | 200, token |
| TC-06 | Вход с неверным паролем | пользователь существует | POST /api/login (WrongPass1!) | 401 |
| TC-07 | Создание мероприятия без токена | не авторизован | POST /api/events | 401 |
| TC-08 | Создание мероприятия организатором | токен организатора | POST /api/events с полным JSON | 201, event_id |
| TC-09 | Создание мероприятия участником | токен роли user | POST /api/events | 403 |
| TC-10 | Регистрация на мероприятие | событие активно | POST /api/events/<id>/register | 201, статус pending |
| TC-11 | Повторная регистрация | заявка уже есть | тот же POST ещё раз | 400 |
| TC-12 | Инклюзивный: фильтр | есть 2 события, одно is_inclusive | GET /api/events?inclusive=1 | только инклюзивные |
| TC-13 | Инклюзивный: цветовой статус | заявка существует | открыть карточку мероприятия | pending — жёлтый, confirmed — зелёный, cancelled — красный, статус продублирован текстом |
 
## Чек-лист
- [ ] Проверено: регистрация принимает валидные данные
- [ ] Проверено: дубли email отклоняются с 400
- [ ] Проверено: вход выдаёт токен
- [ ] Проверено: неверный пароль даёт 401
- [ ] Проверено: без токена создание мероприятия запрещено
- [ ] Проверено: организатор создаёт мероприятие
- [ ] Проверено: участник не может создать мероприятие (403)
- [ ] Проверено: заявка создаётся со статусом pending
- [ ] Проверено: повторная заявка отклоняется
- [ ] Проверено: фильтр инклюзивных работает
- [ ] Проверено: подтверждение заявки создаёт уведомление участнику
- [ ] Проверено: чат сохраняет и отдаёт сообщения
