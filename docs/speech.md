# Тезисы защиты проекта AccessEvent
 
1. **Введение:** Представление проекта AccessEvent — веб-платформы инклюзивных мероприятий для людей с нарушениями слуха.
2. **Проблема и цель:** Решение проблемы хаотичной публикации доступных событий и отсутствия адаптированной коммуникации.
3. **Функционал:** Реализовано 15 функциональных требований (FR), включая фильтрацию инклюзивных событий, систему заявок со статусами, визуальные уведомления и текстовый чат.
4. **Стек и Архитектура:** Python/Flask, PostgreSQL 16 (8 таблиц, 11 внешних ключей), JWT-авторизация, контейнеризация Docker и публикация образов в GHCR.
5. **Тестирование:** Проект полностью покрыт автоматическими тестами (20 PASSED через pytest), настроен CI/CD через GitHub Actions.
